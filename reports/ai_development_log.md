# AI 辅助开发记录

> 本记录整理 AI 工具辅助完成本项目的过程，按"AI 做了什么 / 开发者如何验证与修正"组织，不包含完整聊天历史，也不包含任何密钥或敏感信息。

## 1. 需求分析

- **AI 贡献**：阅读实验需求说明书与赛题命题说明，提炼出"Evidence First、No Evidence No Answer、Text 与 Table 分路径"三大原则，以及"文本检索 + 表格结构化取数"两条独立路径的技术方案。
- **开发者验证**：对照需求书逐条核对最低完成要求（8 条）与验收场景，确认技术方案覆盖全部要求。

## 2. 架构设计

- **AI 贡献**：设计统一数据 Schema（`TextChunk` / `TableRecord`）、模块划分（parsers / knowledge / retrieval / table_query / qa / evaluation）与 CLI 接口（index / ask / evaluate / demo）。
- **开发者验证**：确认模块边界清晰、无循环依赖，路径统一由 `config.py` 管理、不写死绝对路径。

## 3. 代码生成

- **AI 贡献**：生成 Word/PDF/Excel 解析器、结构识别、Chunk 切分、BM25 检索、表格查询引擎、问答流水线、评测与错误分析等模块代码。
- **开发者验证**：每个核心模块完成后立即运行验证，未一次性堆砌代码（Implement → Run → Fix 循环）。

## 4. 主要 Bug 与修复过程

1. **python-docx 导入错误**：`from docx.document import Document` 不能直接实例化。修复为 `from docx import Document`。
2. **表格取数取错单元格**：指标匹配被"机构名"标签污染（"A机构"与"营业收入"同列，机构名匹配得分 100 导致"总资产"被误选）。修复：识别"机构类"标签并在指标匹配时跳过。
3. **机构抽取错误**：正则把 `A机构` 捕获成 `A`（只捕获字母）；且"商业银行"被误判为机构导致全部拒答。修复：用完整匹配 `m.group(0)`，并对抽取的机构做"是否出现在数据标签中"的验证。
4. **指定年份未命中却仍返回答案**：`2020年` 问题因"季度"部分命中返回了 2023 年数据。修复：指定期间时要求期间完全命中，否则拒答。
5. **路由错误**：`单笔贷款金额超过多少万元` 这类阈值题因含"万元"被误路由到表格路径。修复：从表格强信号词中移除裸单位（万元/亿元），保留具体指标名与期间信号。

## 5. 测试发现

- 初次评测准确率 90%（18/20），定位到两处：路由错误 1 例、拒答阈值 1 例。
- 修复后准确率 95%（19/20），最后通过设置文本拒答覆盖率阈值（0.6）达到 100%。

## 6. Evaluation 问题与调优

- 拒答阈值初值为 0（永不拒答），导致"应拒答"问题误答。通过打印各题关键词覆盖率，发现可答题覆盖率=1.0、拒答题覆盖率≈0.56，将阈值设为 0.6 后正确分离。

## 7. 最终优化

- 采用 **Error-driven Development**：先跑通 BM25 + 表格取数，再根据错题优化路由、指标匹配与拒答阈值，而非一开始引入大模型或复杂框架。
- 保持无 API 模式可运行：默认使用抽取式回答，LLM 与 Embedding 均为可选增强。
